# 🦜 Parrot Type

A minimalist, customizable typing test designed to help you measure and improve your typing speed and accuracy. Heavily inspired by [Monkeytype](https://monkeytype.com).

## ✨ Features

- **Distraction-Free Interface:** Clean, minimalist design that keeps your focus entirely on the words.
- **Real-Time Metrics:** Track your Words Per Minute (WPM), raw speed, accuracy, and consistency as you type.
- **Smooth Caret & Feedback:** Instant visual feedback for correct, incorrect, and missed characters.
## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Navigate to the project directory:
   ```bash
   cd parrot-type
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
